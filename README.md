# Reykjavík 2026 – Party Election Quiz Overview

An interactive overview of party positions from the [RÚV Kosningapróf](https://kosningaprof.ruv.is) (election quiz) for the 2026 Reykjavík municipal elections.

**Live site:** https://sagehefring.github.io/rvk/

## What it does

Displays each quiz question alongside the answers and reasoning from every party, so you can compare positions side by side at a glance.
